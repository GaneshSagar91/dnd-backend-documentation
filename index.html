1. Client Apps Layer
  • Customer App (iOS/Android): Cart, live map, OTP

  • Auth & KYC Domain: OTP, tokens, document workflows
  • Catalog & Merchant Domain: Menus, items, store hours
  • Dynamic Slab Pricing: 0-7km distance matrix
  • Order State Machine: Invariant enforcement (READY)
  • PostGIS Dispatch Router: 7km radial courier broadcast
  • Extra Hands Engine: Bidding, hourly & custom errands
4. Realtime & Concurrency Engine
  • Socket.IO Gateway: Multiplexed order, partner & merchant rooms
  • Redis 7 Redlock: Concurrency mutex (prevents double acceptance)
  • Geospatial GEOADD Cache: High-velocity courier coordinates
  • Redis Pub/Sub Bus: Distributed cross-instance sync
5. Storage & Financial Ledger
  • PostgreSQL 16 Engine: ACID transactions, relational integrity
  • PostGIS Extension: Spatial GIST index, ST_DWithin queries
  • Double-Entry Financial Ledger: Immutable journal entries
  • Auditable Balance Guarantee: Σ Debits ≡ Σ Credits
6. 3rd-Party Cloud Integrations
  • Razorpay Payments: Escrow pre-auth, Route automated payouts
  • Google Maps / OSRM: Geocoding & distance calculation
  • Twilio & Firebase FCM: Transactional SMS & push alerts
  • AWS S3 / Cloud Storage: Encrypted KYC docs & catalog media

DevOps & Setup

Developer Quickstart Guide

Terminal: Start Postgres PostGIS & Redis PowerShell 
# 1. Launch Docker containers
docker compose up -d

# 2. Check container health
docker ps
Containers: dnd_postgres_postgis on 5433, dnd_redis on 6379.
Terminal: Install, Migrate & Seed PowerShell 
# 3. Install packages
npm install

# 4. Run PostGIS schema & initial seed
npm run migrate
npm run seed

# 5. Start dev server with watch
npm run dev
Live Server runs on http://localhost:5000.
ZERO-DOCKER READY

Want to run without Docker?

Docker is completely optional. You can connect the backend to free managed cloud instances or run native services on Windows.

Method 1: Free Cloud DBs (Zero Local Setup)
  • PostgreSQL + PostGIS: neon.tech or supabase.com
  • Redis: upstash.com (Free serverless tier)
  • Set DB_SSL=true in .env
Method 2: Native Windows (Local Services)
  • PostgreSQL 16 installer + PostGIS 3.x via Stack Builder
  • Redis: memurai.com (Free Windows developer service)
  • Set DB_PORT=5432 in .env
